### 3系統の使い分け

| 系統 | いつ使う | 強み | 弱み |

## 7. 主要分析結果の統合サマリー

### 7.1 地域分類（8km圏・公開統計）

| 分類 | 該当院 | 特徴 |
|------|--------|------|
| A: 努力で伸びやすい | 本院・所沢・津田沼・市川 | 競合密度36〜39/10万高齢者 |
| B: 中間市場 | 府中・調布・ひばりが丘・西日暮里 | 営業力の差が出やすい |
| C: 構造的に厳しい | 三軒茶屋・三鷹・高円寺・石神井 | 競合54〜65/10万、重複6〜10院 |

### 7.2 施設密度 vs 施設患者比率

- 入所施設密度と施設患者%の相関: **r ≈ -0.36〜-0.38**（施設が多い地域ほど施設%が低い傾向）
- **地域だけでは説明しきれない** → 開院時期・営業戦略の差が大きい
- 施設偏重（地域期待より高い）: 本院・所沢・ひばりが丘・石神井
- 居宅偏重（地域期待より高い）: 津田沼・調布・西日暮里・市川

### 7.3 ひばりが丘 — 確定した分析結論

**プロファイル**:
- 開院2022-08 / 施設重視期 / 515患者（居宅120・施設395）
- 居宅シェア **0.9%**（多摩で府中1.6%・調布2.0%より大幅に低い）
- CM拠点214あるが **居宅÷CM拠点 = 0.56**（府中0.99・調布1.15の半分以下）
- 16km圏わかさ重複 **8院**
- 努力指数669（全院上位）だが収益指数139/医師（施設77%が要因）

**居宅増の優先施策**:
1. 重点CM 20〜30拠点の月次管理（「広さ」→「深さ」）
2. 多摩5院のエリア分担（主戦場: 西東京・東久留米・清瀬・小平北部）
3. 府中・調布の転換期モデル（居宅獲得プロセス）の横展開
4. 病院退院ルート・訪問看護288ステーション連携

**目標（ユーザー合意ベースの提案）**:
- 12ヶ月: 居宅 **160人**（+40、府中並み）
- 24ヶ月: 居宅 **210人**（+90、府中〜調布並み）

**PR #3 追加知見（北多摩北部3市）**:
- 居宅開拓優先度: **東久留米 ＞ 清瀬 ＞ 西東京**
- 東久留米: 在支診密度最低、ひばりが丘から1.6km → **主戦場に最適**
- 西東京: 市場最大だが供給過多 → 新規開拓より施設→居宅転換

## 8. 分析方法論メモ

### 8.1 系統A（analysis/）の前提

| パラメータ | 値 |
|-----------|-----|
| 半径 | 8km |
| 推定居宅需要 | 65歳以上人口 × 4.5% |
| 訪問診療推計 | 一般診療所 × 20.5% |
| 訪問病院推計 | 病院 × 25% |
| 重み付け | 自治体中心点からの距離で簡易交差比 |

**主要KPI（performance_analysis.py）**:
- 収益指数/医師 = (居宅×1.0 + 施設×0.4) / FTE
- 居宅シェア = 居宅患者 / 推定居宅需要
- 努力指数 = 実患者合計 / 理論獲得枠 × 100
- 成果スコア = 地域難易度補正後の効率

### 8.2 系統B（home_visit_demand）の改善点

- 1/4メッシュ（250m）人口 × 半径円交差
- NDB都道府県別・居宅/施設別受療率
- 介護情報公表システムの入居系施設（座標・定員）
- 在支診（関東信越厚生局名簿）
- 実績キャリブレーション（calibrate.py）

### 8.3 系統C（home_care_target）のKPI定義

| 指標 | 意味 |
|------|------|
| 実務KPI | 成熟院: 実績＋増分 / 居宅シフト。本命 |
| 公平シェアKPI | 需要÷実効競合。参照 |
| 居宅ミックス目標 | 40%（伸長50%） |
| 実効競合 | 機能強化型×1.0 + 従来型×0.35 + 在支病ウェイト |
