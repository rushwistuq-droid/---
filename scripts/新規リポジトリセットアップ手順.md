## 2. 新規リポジトリ作成（推奨手順）

### Step 1: GitHub で空リポジトリを作成

- 例: `wakasa-clinic-analysis`（private 推奨）
- README / .gitignore は **追加しない**（ZIPから持っていく）

### Step 2: ZIP を展開して push

```bash
unzip wakasa-clinic-analysis-handover.zip
cd wakasa-clinic-analysis-handover

git init
git branch -M main

# .gitignore を確認（confidential が除外されていること）
cat .gitignore

git add .
git status   # ← confidential/ が含まれていないことを必ず確認

git commit -m "Initial import: Wakasa clinic regional and home-care analysis"
git remote add origin git@github.com:YOUR_ORG/wakasa-clinic-analysis.git
git push -u origin main
```

### Step 3: 機密データの扱い

| 方法 | 内容 |
|------|------|
| **推奨** | `analysis/confidential/` は `.gitignore` 済み。各開発者のローカルのみ |
| 代替 | GitHub Secrets + CI で注入（チーム運用時） |
| **禁止** | operational_data.yaml を public リポジトリに commit |

ZIP には引き継ぎ用に confidential を同梱しています。**push 前に `git status` で漏れがないか確認**してください。

## 3. 環境セットアップ

### 最小構成（系統Aのみ）

```bash
python3 analysis/wakasa_clinic_regional_analysis.py
python3 analysis/performance_analysis.py

```

### フル構成（系統B + C）

```bash
# 系統B
cd home_visit_demand
pip install -r requirements.txt
python3 scripts/build_v2_datasets.py          # 初回のみ（数分）
PYTHONPATH=src python3 -m home_visit_demand "埼玉県所沢市若狭4-2468-31"

# 系統C（Bに依存）
cd ..
pip install -e home_care_target/ 2>/dev/null || pip install pyyaml

python3 -m home_care_target.cli

python3 -m home_care_target.cli --dashboard --write-outputs

# 本部パイプライン（系統B）
cd home_visit_demand

```
